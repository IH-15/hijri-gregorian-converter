# 📅 Hijri & Gregorian Date Converter CLI

An interactive Python command-line interface (CLI) tool designed to convert dates seamlessly between the Gregorian calendar and the Hijri (Islamic lunar) calendar system. Built with input validation, error handling, and clean CLI formatting.

---

## 🚀 Features

* **Interactive CLI:** Prompts the user step-by-step for Day, Month, and Year inputs.
* **Clear Input Guidance:** Displays explicit formatting examples (`DD/MM/YYYY`, e.g., `24/08/2026`).
* **Robust Error Handling:** Catches invalid dates and non-numeric inputs gracefully without crashing.
* **Modern Dependencies:** Powered by the lightweight `hijridate` library.
